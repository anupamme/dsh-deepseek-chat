# dsh-chat

**dsh-chat** 在 DeepSeek Harness（DSH）桌面版中提供 `CHAT | HARNESS` 切换。CHAT 的主区加载真实的 [DeepSeek Chat 官网](https://chat.deepseek.com/)，由官网处理网页登录、聊天和网页账号历史；HARNESS 保留原 DSH 工作区。

当前插件版本为 **0.1.8**，针对 **DSH 0.2.0-rc.2**。两种模式共用DSH原侧栏：顶部、背景材质和底部账号保持一致，CHAT中间区域显示官网真实对话列表，并隐藏插件导航行。官网列表选择、顶部/折叠新建及往返已有实测；系统语言、暗色和标题/分享布局已在目标版本实测。首次正常网页登录后，已多次完整退出 DSH 并重开，恢复同一官网账号和简体中文。本轮修正了加载时反复清空页面/导航和偏好同步重复触发的问题；本机重启后的短时观察中未复现标题与列表闪烁，展开/折叠的标题展示、圆角编辑框和HARNESS/CHAT往返也已复查。长期使用、其他官网状态、发送及另一浏览器历史一致性仍待验证。

## 使用方式

1. 在 Harness 原账号入口完成 DeepSeek 账号授权。授权尚未确认时，整个切换控件禁用。
2. 授权确认后手动选择 CHAT，首次使用在真实官网网页中正常登录。网页登录与 DSH 授权独立；登录后确认“已记住网页登录”，之后同一 DSH 账号可恢复这次官网登录。
3. 从左侧分组列表选中官网对话，点击顶部“新会话”或“对话”标题旁的＋新建官网对话；官网未登录/未就绪时新建禁用。搜索仅筛选已加载标题。右侧聊天仍使用官网页面，数据由官网存储，插件不维护另一份聊天记录；官网全部管理操作尚未镜像。
4. 手动返回 HARNESS 时保留网页容器，恢复进入前的主面板；再进 CHAT 继续使用同一网页。插件不会主动更改右栏的宽度、标签或全屏状态。

切换器位于左侧顶部DeepSeek品牌行的右边，剩余间距自动填充，选中的一侧使用白色底。整个插件网页工具栏已移除；网页加载失败时在故障卡片中重试。侧栏折叠时仅保留原生样式的展开/新建图标，展开后回到左侧品牌切换器。

授权检查失败或超过35秒时，在顶部切换器旁显示原因和“重试授权检查”；未确认账号的控件保持禁用，不会一直停在“正在确认”。正常授权时不显示常驻刷新按钮。普通网络故障不视为退出登录，已确认有效的账号保持当前模式。

## CHAT设置

在DSH原生“设置”中打开“CHAT设置”。精简页只显示官网已登录账号、退出当前账号和系统语言；未登录时显示官网登录页。CHAT使用暗色，不提供外观选择。

默认使用简体中文；你主动选择其他语言后，插件保存并恢复该选择。旧版未设置语言的配置按简体中文处理，网页重新加载或重新登录后再次应用偏好。语言通过官网公开设置控件修改并读回，非敏感偏好由DSH官方配置服务保存。在目标DSH版本中已实测中文/英文往返修改并读回、配置保存和重新打开设置读回。多次完整退出重开后已读回简体中文；退出当前账号入口已实现，实际退出清除与重新登录仍待验证。

### 记住网页登录

0.1.8 新增网页登录保存与恢复：第一次在插件内正常登录官网后，只保存该网页自己的最小登录授权；下次同一 DSH 账号进入 CHAT 时恢复，并由官网重新验证。此功能使用 DSH 官方凭据服务，不需要修改 DSH 安装包，也不使用 DSH 的平台令牌替你登录官网。在本机 DSH 0.2.0-rc.2 中已多次完整退出并重开，官网自动恢复同一账号，无需再次输入登录信息或验证码。

安装或更新后，请先完整退出并重新打开 DSH，让新的保存服务生效。在「CHAT设置」中正常登录，并确认出现“已记住网页登录”，再检查下一次启动的恢复效果。首次升级后可能需要登录一次。加载时会显示打开官网或连接中的状态及重试入口，恢复时需等待官网验证；按最新使用需求，插件自动关闭官网这条固定的“使用环境异常”说明；连续两次完整退出重开已确认无需手动点X，官网主界面和置顶列表正常出现。仅处理这条固定中英文说明，其他提示、验证码与认证错误仍由官网处理。

授权过期、服务端撤销或官网登录格式变化时，仍需正常官网登录。“退出当前账号”会先清除插件保存的这份授权，避免下次自动恢复已退出的登录。不会保存密码、Cookie、聊天正文、草稿或另一浏览器的登录数据。

## 构建与安装

开发环境：Node.js 22.19+ 或 24+、pnpm 10.33.2。运行兼容目标：DSH 0.2.0-rc.2 / Cordis 4.0.4 / React 18.3.1；其他版本待验证。

```bash
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm package:plugin
```

运行打包命令后生成 `artifacts/dsh-chat-0.1.8.tgz`。它包含 Host、Client、类型声明和官方 bundle patch。通过 DSH 官方插件管理器安装本地 tarball；CLI 示例（将路径替换为你的实际文件）：

```bash
dsh plugin --profile desktop add /absolute/path/dsh-chat-0.1.8.tgz --ignore-scripts
```

若使用其他 profile，替换 `desktop`。目标 DSH 0.2.0-rc.2 更新现有插件会要求 `restart-required`；安装后完整退出并重开 DSH，让新 Host 生效。卸载可通过原插件管理界面，或：

```bash
dsh plugin --profile desktop remove dsh-chat
```

从旧版本改名升级时，先在 DSH 插件管理器中禁用并移除旧名称的插件，再安装 `dsh-chat`，避免两份插件同时接管界面。插件改名会创建新的网页容器，可能需要重新登录官网。

### 从 GitHub 地址安装

仓库只保存源码；Git 安装必须允许插件的 `prepare` 构建，才能生成 `lib/index.js` 与 `lib/client.js`。仅下载源码或使用 `--ignore-scripts` 安装 Git 依赖会缺少入口，启用时显示 `failed to import`。

使用固定提交安装：

```bash
dsh plugin --profile desktop add "github:xingxingbk-git/dsh-chat#<完整提交哈希>"
```

将占位哈希替换为实际提交。DSH 0.2.0-rc.2 内置 pnpm 11：首次执行会提示 `ERR_PNPM_GIT_DEP_PREPARE_NOT_ALLOWED`，按它打印的准确 Git 包标识在 `$DSH_HOME/profiles/desktop/pnpm-workspace.yaml` 中增加 `allowBuilds`，再重试。保留已有配置，只允许本次指定提交，不要全局允许所有依赖脚本。普通 pnpm 10 的 CLI 可用 `--allow-build=dsh-chat`，该参数不能替代 pnpm 11 的 Git 身份许可。

构建执行本仓库的脚本；不希望在安装时构建可使用上面的预构建 `.tgz`。

完整安装规则参见 [DSH 官方插件安装文档](https://deepseek-harness.github.io/deepseek-harness/en/develop/basic/publish)。候选版在独立 Web profile 可检查打包和 Host 加载；Web profile 没有 Desktop Browser 桥，CHAT 会明确保持禁用。

## 当前限制

- 右侧正文与编辑器由官网绘制；左侧是对已加载官网导航的界面镜像，按官网分组显示。它依赖网页结构，结构不匹配时恢复官网原导航并提示；这不是官方历史API。空账号、动态加载更多及官网结构变化仍需扩大验证。
- DSH 授权和网页登录互相独立，插件不能确认两处是否为同一账号。DSH 官方确认退出/授权失效会回 Harness；通过插件“退出当前账号”发起退出时，官网登录页确认后回HARNESS并禁用切换器，可在CHAT设置重新登录；已确认登录的官网后来跳回登录页时也会回退；检测依赖约1.2秒的界面轮询，仍无官方退出事件。
- DSH 官方 Browser 的完整网页分区仍只保留当前应用进程；插件保存官网自身的最小登录授权，在新网页中恢复并由官网验证，已通过同账号多次完整退出重开。它不共享 Safari/Chrome 登录；授权过期、撤销、账号切换及卸载清理仍未实机验收。语言偏好单独通过 DSH 官方配置保存，服务器历史由官网恢复。
- 手动模式切换保留网页；插件卸载、DSH 授权失效或账号代次变化会销毁容器。未发送草稿和网页在途生成无法由插件提取、备份或调用官网停止接口。
- 本版适配顶部“新会话”的鼠标/Enter点击，CHAT转交官网；Harness快捷键/菜单仍执行Harness行为，可能创建新的Harness会话并退出CHAT。侧栏结构不匹配会提示并保留原顶部行为，CHAT可使用列表标题旁＋。
- 原生 Browser 安全策略会限制下载、设备权限及部分弹窗；网页登录、验证码、上传等须实测。普通 Web 浏览器版暂不开放 iframe 回退。

## 插件图标

插件管理列表使用 `assets/icon.svg`。替换该文件即可修改图标，重新打包并安装后生效。请保持 SVG 自包含、不引用外部图片或字体，文件不超过 256 KiB；它只影响插件管理图标，不替换 DSH 左上角品牌。配置在 `package.json` 的 `icon` 字段中，资源已加入发布清单。

## 权限与数据流

插件通过官方公开接口读取不含凭据的 DSH 授权状态和账号标识。网页使用 DSH 批准的隔离 Browser guest。页面适配读取官网导航标题/分组/链接/选中状态、公开账号昵称与语言/主题值，操作官网公开控件、固定暗色并隐藏重复侧栏；导航与显示资料仅留在当前授权代次内存，语言偏好由 DSH 官方配置保存。

在用户要求记住网页登录的范围内，登录模块只处理插件自身 `chat.deepseek.com` 网页的 `userToken`、`__appKit_userInfo` 中的账号 id、`deepseek-device-id:chat` 三项白名单数据，使用 DSH 官方 `credentials` 服务保存插件自己的授权记录，并按已确认的 DSH 账号隔离。授权不进入界面状态、普通配置、日志或聊天记录。这依赖官网当前实现，并非稳定的官方 OAuth 接口；保存成功也不代表官网一定接受恢复。

不读取密码、Cookie、其他站点存储、DSH/其他插件的令牌或聊天正文，不调用私有认证接口，不关闭网页安全策略或修改 DSH 安装包。DSH 侧栏适配只调整已批准的品牌间距、插件行显示与顶部新会话点击，禁用时恢复原行为。

插件没有独立模型发送或本地聊天存储功能；不会把 DSH API 生成的对话冒充官网历史，也不自动合并账号数据。网页里的数据处理遵循官网自身行为。
